# 場景卡（scenes）— 跨語言寫作資產

> 本檔是**跨語言資產**：任何語言寫句子都照這張卡，**不得照其他語言的句子改寫**。
> 句子庫見 `quotes.md`；寫作規格見 `quotes.md` §1–§6；widget 實作見 `widget.md`。

## 使用規則

1. **卡片裡沒有句子**，只有情境。看到句子就代表還在翻譯，不是在創作。
2. **寫句子的人只看卡**：情境決定內容、嘲點角度決定怎麼講、「被說中的點」決定讀者要「對」在哪裡。
3. **一張卡只能有一個「被說中的點」**，兩個就代表情境太雜，要拆卡。
4. 每型 30 張：`G` 9／`B` 7／`P` 7／`W` 7。
5. 嘲點角度分配（每型）：目標 自嘲 12／誇張 8／吐槽 10，允許 ±2 條；但**每個標籤至少要用到 2 種角度**，不得一整類只有一種語氣。
6. 每句寫完要過兩件事：**先笑**、**再想「我真的是這樣」**（見 `quotes.md` §4.6），以及**每個名詞都聽得懂**。

## 欄位

| 欄位 | 意思 |
|---|---|
| `idx` | 對應 key，例 `INTJ-G01` → `quote.intj.goal.1` |
| 情境 | 一句話描述生活處境，不含句子 |
| 嘲點角度 | 自嘲／誇張／吐槽（依配額） |
| 被說中的點 | 讀者心裡會「對」的那一下 |
